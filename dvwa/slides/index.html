DVWA Cybersecurity Course

Un corso completo di sicurezza informatica basato su DVWA (Damn Vulnerable Web Application). Impara a identificare, sfruttare e mitigare le vulnerabilità web più comuni.

📚 Moduli del Corso

01

Brute Force

Scopri come funzionano gli attacchi brute force contro i sistemi di autenticazione e impara a implementare difese efficaci.

Low Medium High
02

Command Injection

Esplora le tecniche di iniezione di comandi di sistema e come prevenire l'esecuzione di codice arbitrario sul server.

Low Medium High Impossible
03

CSRF

Comprendi gli attacchi Cross-Site Request Forgery e impara a proteggere le applicazioni web con token anti-CSRF.

Low Medium High
04

File Inclusion

Analizza le vulnerabilità LFI e RFI che permettono di includere file locali o remoti in modo non autorizzato.

Low Medium High
05

File Upload

Scopri i rischi legati all'upload di file non validati e come implementare controlli di sicurezza robusti.

Low Medium High Impossible
06

Insecure CAPTCHA

Esamina le implementazioni insicure dei CAPTCHA e apprendi le best practices per una validazione corretta.

Low Medium High Impossible
07

SQL Injection

Approfondisci una delle vulnerabilità più pericolose: la SQL Injection. Impara a estrarre dati e a proteggere i database.

Low Medium High
